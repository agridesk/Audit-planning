AMS AUTH EXCHANGE SECRET
DATE 2026-09-25

Purpose
Separate short-lived identity-proof signing from the Cloud Run application-session signing key.

Secret Manager name
AMS_AUTH_EXCHANGE_SECRET

Security boundary
- Apps Script may use this exchange secret only to sign a canonical identity proof after validateTrustedTokenByRole succeeds.
- Cloud Run verifies the proof and issues the application session.
- Apps Script never receives AMS_SESSION_SIGNING_SECRET.
- Browser never receives either secret.
- exchange challenge lifetime: 90 seconds.
- exchange challenge is single-use.
- proof binds exchangeId, canonical email, canonical role and exact challenge expiry.

Deployment
cloudbuild.ams-transport-proof.yaml binds AMS_AUTH_EXCHANGE_SECRET:latest to Cloud Run.

PROD untouched.
