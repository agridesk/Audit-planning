PURPOSE
Bring the external Manager 2.0 Completed view to functional parity with the useful read-only history shown in Manager 1.0, without touching planning, lifecycle writes or the pending Plan/login route.

SOURCE OF TRUTH
Completed history remains Log realized audits.
The existing external endpoint /api/v1/manager/archived reads this source read-only.
No new data owner, projection writer or completion logic was introduced.

1. MANAGER 1.0 COMPLETED HISTORY FIELDS
Manager 1.0 shows:
- Company
- Region
- Scopes
- Executed on
- Auditor
- Hours planned
- Hours dedicated
- Completed date
- Status

The history is explicitly read-only.

2. PREVIOUS MANAGER 2.0 BEHAVIOUR
The external Completed tab reused the Open-audits table layout.
This compressed completed data into open-audit columns and therefore hid the distinction between:
- execution date;
- completed date;
- hours planned;
- hours dedicated.

3. IMPLEMENTED ON DEV
Files:
- cloudrun/transport-proof/manager-portal.html
- cloudrun/transport-proof/manager-portal.js

Changes:
- Open and Completed now have separate table headers.
- Completed now displays the same nine useful historical fields as Manager 1.0.
- Completed remains read-only and has no Actions column.
- Search covers completed-specific fields including auditor, execution/completion dates and hours.
- Open-audit actions, including Plan, Approve, Cancel and Reject, are preserved unchanged.
- Table shell now handles wider history data with horizontal overflow instead of compressing/hiding columns.
- Empty-result state added.

4. NOT ADDED
No write action was added.
No correction of completed hours was added.
No export was added because no Manager 1.0 export requirement was evidenced in the reviewed Manager UI.
No sorting enhancement was added in this step; this can be treated as later UI polish unless operationally required.
