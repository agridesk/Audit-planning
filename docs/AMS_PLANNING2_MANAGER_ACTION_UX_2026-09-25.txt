AMS PLANNING 2.0 MANAGER ACTION UX
DATE 2026-09-25
STATUS LOCKED

Manager Portal 2.0 does not copy the legacy Manager 1.0 action surface.

User-facing rule:
- CANCEL and DENY are fused into one Manager action: CANCEL.
- REJECT remains a separate action and lifecycle outcome/status.
- APPROVE remains distinct.
- PLAN belongs to Planning 2.0 workspace, not the grid action column.

Migration rule:
- The UI exposes one CANCEL action wherever the canonical backend currently allows CANCEL or DENY.
- REJECT is never folded into CANCEL.
- Existing backend transition semantics remain canonical during migration; the UI fusion must not create a second lifecycle owner.
